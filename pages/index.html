      What this is

      ResearchRAG answers questions about academic papers so that every claim is traceable (paper, page and verbatim passage), verified (unsupported claims and fabricated quotes are removed or flagged), abstaining ("not enough evidence" instead of a guess) and measured (retrieval, faithfulness, correctness and abstention with confidence intervals, gated in CI).

      The production stack is FastAPI + PostgreSQL/pgvector (HNSW + full-text, Reciprocal Rank Fusion, reranking, MMR), structured generation with JSON repair, claim-level verification, prompt-injection defences, OpenTelemetry traces and Prometheus metrics. GitHub Pages cannot run that server, so this page shows outputs precomputed by the same pipeline code in an in-memory index.

      Honest caveats

      • The corpus is synthetic and small; real-world performance will be lower.
      • The mock LLM copies sentences, so faithfulness is high by construction; it measures the pipeline, not model quality.
      • The offline lexical verifier agrees only weakly with hand labels (Cohen's kappa 0.24); use the LLM or NLI judge with real models.

      Run it yourself (free, no API keys)

      git clone https://github.com/PiyushDas-2004/ResearchRAG.git && cd ResearchRAG
docker compose up -d --build
docker compose exec api sh -c "researchrag corpus build && researchrag ingest data/corpus/pdfs"
# open http://localhost:8000  (API key: dev-local-key)
